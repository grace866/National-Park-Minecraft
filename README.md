# National-Park-Minecraft

Documenting minecraft project created in C++ using OpenGL!
created by Grace Tan, Gracie Yang, and Avery Elliot

Features include 
- game engine tick function and player physics (Avery)
- multi-threaded terrain generation (Grace)
- texture mapping and animation (Gracie)
- trilinear-interpolated, procedurally generated biomes (mountains, forest, desert, lava rock, geysers) (Grace, Gracie)
- procedural cave systems (Avery)
- L system rivers (Grace)
- screen-space reflections using deferred rendering (Grace)
- shadow mappping (Gracie)
- weather (Avery)
- day/night cycle (Avery)
- AI pathfinding npcs (Gracie)
- procedurally placed assets (trees, flowers) (Grace)

More coming soon...
